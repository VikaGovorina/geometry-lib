# Библиотека для работы с геометрическими фигурами.

## Описание

Библиотека предоставляет функционал для создания и взаимодействия с геометрическими фигурами, такими как прямоугольник, круг, треугольник.

## Функционал

- Поддержка прямоугольника
- Поддержка круга
- Поддержка треугольника
- Подсчет площади фигуры
- Подсчет периметра фигуры
- Проверка фигуры
- Системы событий на основе EventTarget
- Поддерка strict Typescript
- Расширяемая архитектура для добавления новых форм

## Установка

```
git clone https://github.com/VikaGovorina/geometry-lib.git
npm install
```

## Build

```
npm run build
```

Скомпилировнные файлы будут сгенерированы в

```
dist/
```

## Использование

```
import { Rectangle, Circle, Triangle } from "./dist/index.js";
```
